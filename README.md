# macui

macui是独立的 macOS 静态壁纸应用。打开「macui.app」，在「发现壁纸」选择图片，按显示器比例预览，再点「设为壁纸」。也可以用「导入」或从 Finder 拖进本地图片。

- 「我的图库」收录收藏、导入和已保存的图片。成功下载的图片可以离线浏览和设置。
- 「最近使用」记录成功应用过的壁纸。菜单栏可切换已下载的图片，也可撤销上次切换。关闭主窗口后仍可使用菜单栏。
- 主窗口从所在显示器的桌面壁纸提取色调，以高对比度的深色呈现。左侧整理题材、图源和图库，中间用列表浏览，右侧大幅预览。分隔线可拖动，收起预览栏后会切换成网格。
- 点「设为 2.5D 动态壁纸」可让桌面上的图片持续产生远近视差。使用随包的 Depth Anything V2 模型在本机生成深度图，离线也可用。默认由独立播放器运行，退出 macui 主程序后仍会播放。可在「设置 → 外观与换图」切换此行为、停止或恢复后台播放。锁屏、息屏和系统「减少动态效果」会暂停动画。
- 静态壁纸之间也可淡入淡出。可在「设置 → 外观与换图」关闭随桌面配色或换图过渡。
- 「国内精选」聚合壁纸仓和 10wallpaper 中文。壁纸仓只收录公开提供图片直链的 4K 条目。两站均可在 macui 内保存离线或设为壁纸，下载时会检查实际像素。
- 侧栏可单独选择图源。原先收藏的彼岸和哲风条目仍可在「我的图库」查看。
- 「发现壁纸」搜索框旁可开启「AI 搜索」。例如输入「薄雾里的墨绿色松林」，模型会提取中英文关键词，应用用这些关键词在图源检索。模型异常时会用原词搜索。
- 在「设置 → AI 搜索」填写 OpenAI 兼容的 API 地址、模型名和 API Key。API Key 存在 macOS 钥匙串，搜索词只在开启 AI 搜索后发给模型。兼容本机 HTTP 和已配置的 HTTP 网关，远程连接建议使用 HTTPS。
- 列表按滚动位置加载缩略图，提前缓存下方图片，接近底部时自动加载下一页。点选时先显示在线预览，按空格放大时加载并验证高清图。保存和应用时按文件像素校验，横图至少 3840 × 2160。
- 在桌面预览中可开启「画质增强」对比轻度降噪和亮度锐化的效果。设为静态或动态壁纸时会使用同尺寸的增强副本，图库保留原图。
- 桌面预览按目标屏幕的实际像素比例显示，提示裁切和放大幅度。开启「匹配显示器比例」后，「填满」会检查所有目标显示器，限制裁切在 18% 内。「适应」保留全图，并用图片边缘的色彩填充空白。
- 「设置 → 下载位置」可以选择在线图片的保存文件夹。「保存离线」和换图时新下载的图片都会存到这里，旧文件仍按原路径读取。
- 下载期间可取消。10wallpaper 有多种高清尺寸时优先选择更适合目标屏幕的版本，验证失败时尝试下一种尺寸。
- 使用 SwiftUI 和 AppKit，目标平台为 macOS 14 或更新版本。首版设置静态图片，撤销使用系统提供的上一张图片路径。系统的动态效果需要在系统设置中重新选择。

## 构建和测试

```sh
swift test
WALLPAPER_WALL_LIVE_TEST=1 swift test
bash Scripts/package-app.sh
```

打包结果位于 `dist/macui.app`，脚本按本机架构构建并做本地签名。首次打包下载并校验固定版本的景深模型，后续复用本机缓存。应用数据保存在 `~/Library/Application Support/WallpaperWall/`。在线结果和可下载尺寸以源站当时返回的内容为准。
